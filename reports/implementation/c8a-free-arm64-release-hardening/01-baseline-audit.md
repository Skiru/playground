# Baseline audit

Start: `bec176bedcdea0e6c662b1992b488554150b06cf`, tree `ff00b539feb0766e61742b022d8779c3dfa22dd5`. The base Compose topology has api, worker, optional discovery workers, web, PostgreSQL/PostGIS, and optional Redis. API and web use digest-pinned multi-architecture FrankenPHP and Node base manifests; PostGIS upstream is explicitly amd64-only. Messenger uses Doctrine. Browser web traffic is server-side proxied to `http://api`; media URLs are generated by the storage adapter. Google credentials are verified by Symfony. Migrations are explicit Doctrine console commands. Discovery already defaults fail-closed and has tests.

Known gaps: no GHCR publisher, no ARM PostGIS, no deployment gateway/tunnel, local media production default, no resource limits, and test-only backup scripts. Local tool versions recorded: Git 2.55.0, Docker 29.1.4, Compose 5.0.1, Buildx 0.30.1, Node 20.10.0; pnpm 11 cannot run under this Node version.
